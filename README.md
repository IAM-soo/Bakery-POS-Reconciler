# Bakery POS Reconciler (ベーカリー レジ締め支援ツール) 🍞

本プロジェクトは、パン屋のレジ締め作業（レジチェック）における誤差の解消を支援するための Python ツールです。

## 1. 開発の背景 (Motivation)
現在アルバイトをしているパン屋では、POSシステムと自動釣銭機（またはキャッシュレジスター）が連動していません。そのため、手入力によるミスが発生しやすく、レジ締め時に金額が合わないことが頻繁にあります。

この課題を解決するために、以下の機能を持つツールを開発しています：
- POSの合計額と実際の現金合計額の差額を即座に算出。
- 差額を修正するために「どの伝票を取消し、どの商品で打ち直すべきか」の最適な組み合わせを提案。

## 2. 主な機能 (Features)
- [ ] **差額計算機能**：POS額とレジ現金額を入力し、誤差を自動算出。
- [ ] **商品組み合わせ最適化アルゴリズム**：当日のメニューに基づき、差額を埋める最適な商品構成を提案（消費税10%対応）。
- [ ] **OCR 画像認識** (開発予定)：スマホでPOS画面を撮影し、金額を自動読み取り。

## 3. セットアップ (Installation)
1. 仮想環境の作成：`python3 -m venv venv`
2. 仮想環境の有効化：`source venv/bin/activate`
3. 依存パッケージのインストール：`pip install -r requirements.txt`

## 4. プロジェクト構成 (Structure)
- `src/`: Python ロジックコード（計算アルゴリズム等）
- `data/`: `menu.json` (商品名・価格データ)
- `tests/`: テスト用スクリプト
